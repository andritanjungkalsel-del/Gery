ZOMBIE SNIPER: RUINS
=====================
Game 3D browser, mobile-first.

Fitur:
- Sniper futuristik dengan scope 200x sebagai efek gameplay.
- Peluru baja adalah atribut fiksi/gameplay.
- Muzzle flash, tracer peluru, impact, recoil/zoom feel.
- Suara tembakan/reload/hit memakai Web Audio API.
- Zombie blocky dan wave.
- Rumah dapat menerima damage dan hancur menjadi debris.
- Joystick, aim, fire, reload untuk HP.

Jalankan:
1. Ekstrak ZIP.
2. Buka index.html melalui hosting/localhost.
3. Internet dibutuhkan karena Three.js diambil dari CDN.

GitHub Pages:
Upload index.html, style.css, game.js ke repository -> Settings -> Pages -> Deploy from branch.
