# Zombie Outbreak 3D
Game 3D zombie berbasis HTML + CSS + JavaScript + Three.js.

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` melalui hosting web atau server lokal.
3. Untuk GitHub Pages: upload ketiga file ke repository, lalu aktifkan Settings > Pages > Deploy from branch.

## Kontrol HP
- Joystick kiri: bergerak
- Geser layar bagian kanan: kamera
- 🔥: menembak
- ↻: reload
- ⬆: lompat

Catatan: Three.js dimuat dari CDN, jadi browser membutuhkan koneksi internet.
